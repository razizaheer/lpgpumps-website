# lpgpumps.in

Website for YAM LPG transfer pumps (Wingz, New Delhi), published by Cloudflare Pages from the `out/` folder.

- `pages/` — English source pages and assets
- `tr/` — translations (`<lang>.tsv`, `landing/`, `pay/`) and `build.py`
- `out/` — the built site in all languages (what Cloudflare serves)

Rebuild: `python3 tr/build.py .`
